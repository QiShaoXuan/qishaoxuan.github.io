   作为秒杀频道 H5 开发一号位，负责大促会场等大流量业务场景开发及日常迭代，主导秒杀主会场性能优化。

   - **资源与数据加载：**通过 Code Review 检查历史遗留逻辑和依赖引入方式，减少构建包体积；首屏仅请求所需数据，其余数据随页面滚动懒加载，将 HTML 中通过 script 引入的 SDK 改为按需动态加载，并添加骨架屏。

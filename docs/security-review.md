# 简历聊天与静态下载安全审查

审查日期：2026-10-21。范围为当前本机代码、接口和真实 DeepSeek 抽样；未修改线上服务，也未自动修复下述聊天接口风险。静态审查、独立复核与动态结果共同构成本记录，不表示已完成渗透测试或保证模型行为。

## 结论

访客不能通过聊天修改服务器上的提示词文件、模型配置或权限；请求拒绝 `system` 角色、自选模型和额外字段，模型也没有文件、Shell 或部署工具。自然语言仍能影响模型输出，不能把“提示词要求拒绝”当作可靠授权边界。本轮确认模型会回答与简历无关的算术题，因此当前问答范围尚不是硬限制。

未发现已确认的密钥泄漏、任意服务器命令执行或任意 URL 抓取路径。独立代码审查仍建议修改：客户端历史可信度、匿名额度消耗和外部资料隔离需要后续加固，GitHub 读取失败的可观测性也不完整。

## 已有防护

- `apps/api/src/app.ts` 严格校验消息角色、轮次、长度和请求体，限制并发、超时、每日调用数和每 IP 频率；代理信任范围限定回环地址。
- `apps/api/src/deepseek.ts` 固定模型服务地址，密钥仅用于上游 Authorization，不进入提示词或前端。服务端日志不存对话正文、完整提示词、密钥及上游响应正文。
- `apps/api/src/github.ts` 仅允许固定公开仓库和固定 GitHub 主机，限制响应大小、时间并拒绝重定向。知识构建只读取批准的公开资料，不扫描私人原始材料。
- 前端以 React 文本渲染回复，不直接执行模型 HTML；引用来源受 HTTPS GitHub URL 校验。浏览器记录按环境命名、七天有效、500 KiB 上限且清空需确认。正式和开发路径属于同源，不构成存储安全隔离。

## 公开内容与 PDF

网页直接显示完整 README，PDF 也包含同一内容。聊天知识构建会裁剪旧版字节项目正文，但这不会删除 README、网页、PDF 或公开来源链接中的内容。当前 README 仍有内部产品名称和精确业务指标；是否公开应以源文档的公开口径为准，不能依赖模型脱敏隐藏已发布内容。本轮按现有简历生成，不擅自修改事实。

下载文件为构建期静态 PDF，名称固定，不接受访客提供路径或生成指令。导出器只渲染简历组件，隔离浏览器实例、禁止页面联网及 Service Worker；没有访问个人 Chrome 登录资料。没有通过抓包验证进程级零外连。生成来源和产物哈希由构建前检查；该检查用于同步完整性，不是数字签名。PDF 中文文本层的定向映射修复不修改字形或内容流。
